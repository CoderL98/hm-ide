# 鸿蒙原生IDE（hm-ide）静态原型

多设备、多方向高保真 HTML 原型，用于演示「鸿蒙原生IDE」桌面 / 平板 / 手机 / 折叠屏界面。无构建步骤，浏览器直接打开即可。

## 文件

| 文件 | 说明 |
|------|------|
| `index.html` | 原型画廊入口（含中文方向标签） |
| `desktop.html` | 桌面端（约 1440×900）：活动栏、资源管理器、标签编辑器、底栏终端、状态栏 |
| `tablet.html` | 平板横屏（约 1024×768）：双栏 + 可折叠底栏 |
| `tablet-portrait.html` | 平板竖屏（约 768×1024）：窄侧栏旁挂编辑器 |
| `phone.html` | 手机竖屏（约 390×844）：编辑焦点 + 底栏导航 |
| `phone-landscape.html` | 手机横屏（约 844×390）：侧轨导航 + 双栏（资源管理器 \| 编辑器） |
| `phone-fold-landscape.html` | 折叠屏横屏（约 1000×600）：近平板 IDE 密度，保留手机态顶栏 |
| `styles.css` | 共享设计令牌、组件与方向壳层样式 |

## 方向策略（Orientation）

运行时支持**方向锁定**与**横竖屏切换**。原型按断点拆分，便于评审布局而非依赖单一弹性页面。

| 形态 | 断点（示意） | 布局要点 |
|------|--------------|----------|
| 手机竖屏 | ~390×844 | 单栏编辑；底栏导航；文件以 Sheet / Chip 进入 |
| 手机横屏 | ~844×390 | 底栏改**侧轨**；窄资源管理器 + 编辑器；紧凑状态栏 |
| 折叠屏横屏 | ~1000×600（展开宽屏） | **近平板密度**：活动栏 + 资源管理器 \| 编辑器 + 可选底栏终端；UI 标注「折叠屏横屏」 |
| 平板竖屏 | ~768×1024 | 侧栏收窄（~200px）旁挂编辑器，纵向留给代码与终端 |
| 平板横屏 | ~1024×768 | 标准双栏 + 可折叠底栏 |
| 桌面 | ~1440×900 | 完整 IDE 五区：活动栏 / 侧栏 / 编辑器 / 底栏 / 状态栏 |

**自适应断点建议（实现层）：**

- `< 600`：手机竖屏逻辑；横屏旋转后切侧轨双栏
- `600–840`：大屏手机 / 折叠折叠态；优先双栏，终端可折叠为条
- `840–1024`：折叠展开或小平板；启用近平板密度
- `≥ 1024`：平板 / 桌面完整壳层

## 设计说明

- **主题**：以 shadcn/ui zinc 深色为主（`zinc-950 / 900 / 800`），近单色；主色仅作稀疏强调。页面右上角可切换浅色变体。
- **气质**：克制、专业、偏 Linear + VS Code 密度；避免紫渐变、霓虹光晕与通用 SaaS 插画。
- **字体**：Inter（界面）+ JetBrains Mono（代码），标题略收紧字距；界面约 12–13px，代码约 12–13px（横屏更密）。
- **控件**：1px 细边框、`rounded-md`（约 6–8px），图标为 16px lucide 风格描边 SVG。
- **编辑器**：`Index.ets` ArkTS 示例，含行号、当前行高亮、脏文件圆点；标签含 `main_pages.json`、`module.json5`。
- **文案**：资源管理器、终端、输出、问题、设置、折叠屏横屏等中文标签。

## 使用

在资源管理器中打开 `index.html`，或于本目录执行：

```bash
python3 -m http.server 8765
```

然后访问 `http://localhost:8765/`。
